> منبع دادهٔ تست: جلسهٔ قبلی «تست پنل پیامک» (فایل `uploads/send-sms-working-recipe.md` در محیط کار — خارج از مخزن).

- زیرساخت کارای حساب: **api.parsasms.com** (نه gateway.ghasedak.me).
- نقطهٔ ارسال تکی: `POST https://api.parsasms.com/v2/sms/send/simple` با هدر `apikey`.
- سرشماره: `10002000100246`.
- پیش از استفاده از هر سرور جدید، IP آن سرور باید در پنل (تنظیمات ← امنیت ← IP های مجاز وب سرویس) ثبت شده باشد.
- کلید API هرگز وارد مخزن نشود.
