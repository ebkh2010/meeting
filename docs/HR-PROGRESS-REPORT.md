## ۵. دو مانع قبل از شروع کد

### الف) تصمیم‌های باز (۹ مورد) — بدون پاسخ شما کد زده نمی‌شود
مهم‌ترین‌ها:
1. **نقش‌ها:** «مدیر استخدام» و «مصاحبه‌گر» به‌عنوان نقش سازمانی جدید اضافه شوند یا فعلاً فقط `org_admin`؟
2. **رزومهٔ اسکن‌شده:** OCR آفلاین اضافه شود (نیازمند wheel جدید) یا پیام «پشتیبانی نمی‌شود» کافی است؟
3. **چند دور مصاحبه:** یک دور یا چند دور (فنی/HR/مدیر) با شاخص‌های جدا؟
4. **مقیاس:** حجم رزومه در ماه (۱۰ / ۱۰۰ / ۱۰۰۰) — تعیین‌کنندهٔ طراحی صف و UI.
5. **ارزیابی ویدیویی (لحن/چهره):** خارج از دامنه بماند؟ (پیشنهاد: بله)
6. **زبان:** فقط فارسی یا دوزبانه؟

_(فهرست کامل در بخش ۱۱٫۲ سند `HR-MODULE-PLAN.md`)_

### ب) دو کار فنی معلق (خارج از کد ماژول، اختیاری)
- **تمدید خودکار گواهی:** به **توکن API آروان‌کلاد** نیاز دارد (پایش هشدار فعال است، انقضا ۵۵ روز دیگر).
- **آینهٔ GitLab:** از سرور در دسترس نیست؛ تا آن زمان به‌روزرسانی با bundle کار می‌کند.
